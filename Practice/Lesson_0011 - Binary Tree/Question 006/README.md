# Build a **binary tree program** that can store the values in the table below.

## Task Requirements

- Display the final **preorder traversal result**
- Display the final **inorder traversal result**
- Display the final **postorder traversal result**
- Estimate **how tall the tree is**
- Determine **how many nodes** the tree has
- Find the **final sum of car prices**
- Find the **final sum of car amounts** in the tree

---

## Car Data Table
| Car ID  | Car Brand | Car Type      | Car Color | Car Price | Car Amount |
|--------|-----------|---------------|-----------|-----------|------------|
| Car0051 | Proton  | X50           | White     | 95000     | 5 |
| Car0302 | Honda   | Civic         | Red       | 135000    | 3 |
| Car0024 | Toyota  | Yaris         | Red       | 87900     | 2 |
| Car0101 | Toyota  | Corolla Cross | Yellow    | 125700    | 5 |
| Car1001 | Perodua | MyVi          | Blue      | 48700     | 2 |
| Car5051 | Mazda   | X30           | Black     | 115000    | 1 |

---

## Output
```
Preorder Traversal: Car0051 Car0024 Car0302 Car0101 Car1001 Car5051 
Inorder Traversal: Car0024 Car0051 Car0101 Car0302 Car1001 Car5051 
Postorder Traversal: Car0024 Car0101 Car5051 Car1001 Car0302 Car0051 

Height of tree: 3
```
