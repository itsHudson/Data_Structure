# Write a C++ program that performs currency conversion between U.S. dollars (USD) and Chinese Renminbi (RMB).

- Your program should:
  - Prompt the user to enter the exchange rate from U.S. dollars to RMB.
  
  - Prompt the user to enter:
    - 0 to convert from U.S. dollars to RMB, or
    - 1 to convert from RMB to U.S. dollars.

  - Prompt the user to enter the amount to be converted:
    - If the user enters 0, input an amount in U.S. dollars and convert it to RMB.
    - If the user enters 1, input an amount in RMB and convert it to U.S. dollars.

  - Display the result of the conversion.


```text
Enter the exchange rate from dollars to RMB: 6.81
Enter 0 to convert dollars to RMB and 1 vice versa: 0
Enter the dollar amount: 100
$100.0 is 681.0 yuan


Enter the exchange rate from dollars to RMB: 6.81
Enter 0 to convert dollars to RMB and 1 vice versa: 1
Enter the RMB amount: 10000
10000.0 yuan is $1468.43
