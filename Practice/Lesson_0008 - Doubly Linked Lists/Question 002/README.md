# Using the **Doubly Linked-List** concept, create a new **music player system**.

Create a music player system that contains the following list:

| No | Artist | Song | Released | Genre | Length |
|----|--------|------|----------|-------|--------|
| 1 | Celine Dion | Just Walk Away | 1993 | Pop | 4.58 |
| 2 | Taylor Swift | You Belong With Me | 2008 | Pop | 3.48 |
| 3 | The Cranberries | Promises | 1999 | Rock | 4.30 |

## Functionalities

The system should support the following functionalities:
- Add a new song at the **beginning** of the current song list
- Add a new song at the **end** of the current song list
- Add a new song at **any position** of the current song list
- View the list **without sorting**
- View the list **sorted by song number**
- View the song list **one by one** by using the **Previous** button and **Next** button
- Delete a song from the **beginning** of the list
- Delete a song from the **end** of the list
- Delete a song based on the **Artist Name**
- Search a song based on the **genre of song**
