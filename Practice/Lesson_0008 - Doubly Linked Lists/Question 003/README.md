# Using the **Doubly Linked-List** concept, create a simple **cloth shopping system** that contains the list below:

| Cloth ID | Cloth Name | Description | Color | Quantity | Category |
|----------|------------|-------------|-------|----------|----------|
| SRT001 | Mickey Mouse T-Shirt | Long Sleeve | Black | 23 | Shirt |
| SRT002 | Butterfly Blouse | Short Sleeve | White | 5 | Shirt |
| SKT001 | Bubble Skirt | Short Skirt | Yellow | 30 | Skirt |
| SKT002 | Jeans Skirt | Long Skirt | Yellow | 14 | Skirt |
| SKT003 | Cotton Skirt | Long Skirt | Black | 15 | Skirt |
| HAT001 | Black Hat | With Apple | Black | 2 | Hat |

## Customer Functionalities
- View all cloth list **without sorting**
- Sort the cloth list based on **Category in descending order** and display it on the screen
- View a **single cloth item one by one** by using the **Previous** button and **Next** button
- Filter the cloth list by searching based on **Color**
- Add a **single order** from the cloth list
- Exit to **Login Page**

## Admin Functionalities
- Add a new cloth into the system
- Delete a cloth from the list based on **Cloth ID**
- View the list **without sorting**
- Sort the list based on **Quantity in ascending order** and display it on the screen
- View all the **customer orders**
- View a **single order one by one** by using the **Previous** button and **Next** button
- Exit to **Login Page**
