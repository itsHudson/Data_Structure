# Given an **infix expression** in the form of string `str`, Convert Infix Expression to Postfix Expression**.

---

## Definitions
- **Infix Expression**  
  The expression of the form **a op b**, where the operator is placed **between two operands**.

- **Postfix Expression**  
  The expression of the form **a b op**, where the operator appears **after the operands**.

### Operator Precedence
The order of precedence is: ^ > * = / > + = -
