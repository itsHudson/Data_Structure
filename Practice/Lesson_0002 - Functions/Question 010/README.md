# Question 1: Differentiate for, while and do...while loops.

### Answer:
The `for`, `while`, and `do...while` loops are used to repeat a block of code, but they differ in structure and behavior.

- The `for` loop is used when the number of iterations is known. It combines initialization, condition, and update in one line, making it suitable for counter-controlled loops.

- The `while` loop is used when the number of iterations is not known in advance and depends on a condition. The condition is checked before executing the loop body, so the loop may not execute at all.

- The `do...while` loop is similar to the `while` loop, but the condition is checked after the loop body executes. This means the loop will always execute at least once, regardless of the condition.

# Question 2: Define recursive function.

### Answer:
A recursive function is a function that calls itself in order to solve a problem. It breaks down a problem into smaller sub-problems of the same type.

A recursive function must have two important parts:
- A base case, which stops the recursion.
- A recursive case, where the function calls itself with a smaller input.

# Question 3: Describe types of selection controls.

### Answer:
Selection control statements are used to make decisions in a program by executing different code blocks based on conditions.

- The `if` statement is used to execute a block of code only when a condition is true.

- The `if...else` statement is used to choose between two alternatives, executing one block if the condition is true and another if it is false.

- The `if...else if...else` statement is used when there are multiple conditions to check, allowing the program to select one option from several possibilities.

- The `switch` statement is used when a variable is compared against multiple fixed values. It provides a cleaner and more organized way to handle multiple choices.
